`o-grid` is an open power system modeling and optimization framework. Its parser
reads power-system cases in multiple formats and converts supported static cases into a typed
[`infrasys`](https://pypi.org/project/infrasys/) component, producing a
validated, queryable `System`:

- **ANAREDE** power-flow cases (`.pwf`) — each execution block is converted into
  a typed component.
- **MATPOWER** cases (`.m`) — the `bus`, `gen`, and `branch` tables are converted
  into the same typed components.
- **ANAREDE NTW** cases (`.NTW`) — network sections are converted into dedicated
  models such as `ShuntDevice`, `SeriesCapacitor`, and `FACTSDevice`.
- **ANAREDE dynamic models** (`.dyn`) — model headers and slash-terminated records
  are preserved in a structured `DynFile` representation.
- **ANAREDE event files** (`.evt`) — contingency definitions and ordered events
  are preserved in an `EvtFile` representation for stability studies.

This documentation is organized by user need.

- **Tutorials** teach the first successful workflow through guided practice.
- **Reference** describes the ANAREDE blocks and the component models.
- **Explanation** describes the design behind the parser.

## Package scope

| Module | Purpose |
| --- | --- |
| `o_grid.parser` | Column-driven ANAREDE reader that populates an `infrasys` `System`. |
| `o_grid.matpower` | MATPOWER `.m` reader (`parse_matpower_system`, `MatpowerInfrasysParser`) that populates the same `System` model. |
| `o_grid.statics.ntw_parser` | ANAREDE `.NTW` reader (`NtwFileParser`) for typed NTW network components. |
| `o_grid.dynamics` | ANAREDE `.dyn` and `.evt` readers plus the reduced-order stability study (`StabilityStudy`). |
| `o_grid.models` | Typed power-system component models (buses, branches, generators, loads, control). |
| `o_grid.plugin_parser` | `r2x-core` plugin wrappers (`AnaredeParser`, `MatPowerParser`) exposing the parsers. |
| `o_grid.plugin_config` | `AnaredeConfig` and `MatpowerConfig`, the configuration models for the parser plugins. |
| `o_grid.exporter` | Writes solved power-flow results to Excel workbooks (`ExportSolution`) and delimited text (`export_rows`). |
| `o_grid.config` | Declarative column mapping (`anarede_mapping.json`) and generator type mapping. |
