---
title: ANAREDE event parser
description: Parse ANAREDE EVT contingency files and use them in stability studies.

---

`EvtFileParser` reads ANAREDE `.evt` files into an `EvtFile` containing the
simulation duration and ordered contingencies. Each `DynamicContingency`
contains `DynamicEvent` records with typed parameters, source line numbers, and
the original raw line.

```python
from pathlib import Path

from o_grid.dynamics import EvtFileParser

evt_file = EvtFileParser(Path("tests/data/evt/9bus.evt")).file
print(evt_file.total_simulation_time)

for contingency in evt_file.contingencies:
    print(contingency.number, contingency.identifier.strip())
    for event in contingency.events:
        print(event.event_type, event.event_time)
```

## File structure

| Record | Meaning |
| --- | --- |
| First non-empty record | Total simulation time in seconds. |
| Contingency header | Sequential number and quoted identifier. |
| Event records | Ten free-format fields describing each event. |
| `-99 /` | Ends the current contingency. |
| `-999 /` | Ends the file. |

## Event fields

| Position | Field | Description |
| ---: | --- | --- |
| 1 | Event type | Integer from the supported event definitions. |
| 2 | Bus 1 | Bus number or branch name. |
| 3 | Bus 2 | Bus number or zero. |
| 4 | Circuit ID | Parallel circuit identifier. |
| 5-7 | Parameters 1-3 | Event-specific real values. Parameter 3 is the event time in seconds. |
| 8-9 | Bus names | Fallback names when the corresponding bus number is zero. |
| 10 | Parameter 4 | Event-specific real value, commonly zero. |

## Event-driven stability study

Pass the parsed or source EVT file to `StabilityStudy` and select a contingency
by number or identifier:

```python
from pathlib import Path

from o_grid.dynamics import StabilityConfig, StabilityStudy

study = StabilityStudy(
    Path("tests/data/ntw/9bus.ntw"),
    Path("tests/data/dyn/9bus.dyn"),
    event_file=Path("tests/data/evt/9bus.evt"),
    contingency=2,
    config=StabilityConfig(duration=10.0, time_step=0.01),
)
result = study.run()
```

When an EVT file is supplied, event times replace the example's hard-coded
fault interval. The current stability engine is reduced-order: branch and bus
events modulate the aggregate electrical transfer factor while the parser
retains the complete event data for future topology-aware simulation. Detailed
network mutation and device-specific event behavior remain future work.
