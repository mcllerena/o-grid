The parser recognizes ANAREDE **execution codes** (blocks). Each block's fields
are sliced by fixed column ranges defined in
[`config/anarede_mapping.json`](https://github.com/mcllerena/o-grid/blob/main/src/o_grid/config/anarede_mapping.json),
then resolved into the typed component registered in `BLOCK_BASE_CLASSES`
([`o_grid/models/__init__.py`](https://github.com/mcllerena/o-grid/blob/main/src/o_grid/models/__init__.py)).

## Topology and buses

| Block | Component | Purpose |
| --- | --- | --- |
| `TITU` | [`CaseTitle`](/0.1.0/reference/models/#casetitle) | System title and description information. |
| `DBAR` | [`ACBus`](/0.1.0/reference/models/#acbus) | AC buses. |
| `DGBT` | [`VoltageBaseGroup`](/0.1.0/reference/models/#voltagebasegroup) | AC bus voltage base group definitions. |
| `DGLT` | [`VoltageLimitGroup`](/0.1.0/reference/models/#voltagelimitgroup) | Voltage operating-limit group definitions. |
| `DARE` | [`AreaInterchange`](/0.1.0/reference/models/#areainterchange) | Active power interchange limits between areas. |

## Branches (lines and transformers)

A single `DLIN` record is classified during parsing and may be materialized as a
line, transformer, or switch depending on its tap and impedance fields.

| Block | Component | Purpose |
| --- | --- | --- |
| `DLIN` | [`ACLine`](/0.1.0/reference/models/#acline) | AC circuits (lines & transformers). |
| `DLIN_TAP` | [`LTCTransformer`](/0.1.0/reference/models/#ltctransformer) | Load-tap-changing transformer derived from a `DLIN` tap range. |
| `DLIN_PHASE_SHIFT` | [`PhaseShiftingTransformer`](/0.1.0/reference/models/#phaseshiftingtransformer) | Phase-shifting transformer derived from a `DLIN` phase angle. |
| `DLIN_TRANSFORMER` | [`TransformerDevice`](/0.1.0/reference/models/#transformerdevice) | Fixed-ratio transformer derived from a `DLIN` tap without a range. |
| `DLIN_SWITCH` | [`SwitchDevice`](/0.1.0/reference/models/#switchdevice) | Switch / low-impedance element derived from a `DLIN` record. |
| `DCSC` | [`ControllableSeriesCompensator`](/0.1.0/reference/models/#controllableseriescompensator) | Controllable Series Compensator (CSC) data. |
| `DSHL` | [`LineShunt`](/0.1.0/reference/models/#lineshunt) | AC-circuit terminal shunt devices. |

## How a block is described

Every field in the mapping declares the columns to slice, a default value, and a
description sourced from the ANAREDE manual. For example, the `DARE` block:

```json
"DARE": {
  "function": "Reading of active power interchange data between areas.",
  "fields": {
    "area_number": {
      "column": { "start": 1, "end": 3 },
      "default": "",
      "description": "Area number, as defined in the Area field of the DBAR execution code."
    },
    "net_interchange": {
      "column": { "start": 8, "end": 13 },
      "default": 0.0,
      "description": "Net active power interchange of the area, in MW."
    }
  }
}
```

To support a new field or adjust a column, edit the mapping — the parsing code
does not change.
